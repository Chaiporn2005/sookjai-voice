# สุขใจ เฮลท์: คุยด้วยเสียงกับน้องสุขใจ (Sookjai Voice)

ต่อยอดจากโปรเจกต์ `Hac`: เพิ่มโหมด**คุยด้วยเสียงแบบ Airlearn** น้องสุขใจยืนกลางจอ ผู้ใช้กดไมค์แล้วพูด AI ตอบกลับเป็นเสียงพร้อมซับไตเติล ตัวละครใช้ภาพจริงจาก `Character_Design.jpg`

> ต้นแบบเพื่อการสาธิต ไม่ใช่เครื่องมือแพทย์ คำตอบของ AI อาจผิดพลาด ไม่ใช่คำแนะนำทางการแพทย์

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (เหมือนโปรเจกต์เดิม + โหมดคุยด้วยเสียง) |
| `assets/character/*.png` | ภาพตัวละครที่ตัดจาก `Character_Design.jpg` (พื้นใส) |
| `worker/worker.js` | Cloudflare Worker: เก็บ API key, ส่งเสียงไป Typhoon ASR, ส่งข้อความไป Typhoon LLM, ส่งคำตอบไปสร้างเสียงที่ Botnoi Voice |
| `worker/wrangler.toml` | ค่าตั้งของ Worker (ชื่อ, เว็บที่อนุญาตให้เรียก) |
| `voice/*.mp3` | เสียงอัดไว้ล่วงหน้าของประโยคตายตัว (คำทักทาย, ตอนแตะตัวน้อง, คำขอบคุณ) สร้างด้วย `tools/make-voice.mjs` |
| `tools/make-voice.mjs` | สร้างไฟล์ใน `voice/` ด้วยเสียงโบผ่าน Worker เสียแต้มครั้งเดียว ข้ามไฟล์ที่มีแล้ว |
| `Character_Design.jpg` | แผ่นออกแบบตัวละครต้นฉบับ |

## การทำงาน

```
มือถือ ──เสียง (WAV)──▶ Cloudflare Worker ──▶ Typhoon ASR (typhoon-asr-realtime) ──▶ ข้อความ
       ◀──คำตอบ──────── Cloudflare Worker ◀── Typhoon LLM (typhoon-v2.5-30b-a3b-instruct)
Cloudflare Worker ──▶ Botnoi Voice (เสียงโบ / Bow V2) ──▶ MP3 ──▶ มือถือเล่นเสียง ปากขยับตามความดังของเสียงจริง
(ถ้า Botnoi ปฏิเสธ เช่น แต้มหมด จะใช้เสียงในเครื่องไปจนปิดหน้าเว็บ ไม่สลับไปมา · ถ้าเน็ตสะดุดจะพัก Botnoi 5 นาที)
ประโยคตายตัว ──▶ voice/*.mp3 (เสียงโบเดียวกัน อัดไว้แล้ว ไม่เสียแต้ม) ──▶ ถ้ายังไม่มีไฟล์จึงใช้ Botnoi หรือเสียงในเครื่อง
```

- **แตะตัวน้องสุขใจ (หน้าแรก):** มีเสียง "ปุ๊ง" สั้นๆ แล้วน้องพูดด้วยเสียงที่อัดไว้ (`voice/hero-poke-1..5.mp3`) ถ้ายังไม่มีไฟล์ น้องจะขยับปากเงียบๆ แทนการใช้เสียงในเครื่อง ปุ่ม "ฟังคำทักทาย" ใช้ `voice/hero-greet.mp3` ถ้าไม่มีจะใช้เสียงในเครื่อง

- **ไมค์:** แตะเพื่อพูด ระบบจะหยุดฟังเองเมื่อเงียบประมาณ 1.3 วินาที (แตะซ้ำเพื่อหยุดเองก็ได้) ระหว่างน้องสุขใจพูด แตะไมค์เพื่อพูดแทรกได้
- **ไฟล์เสียง:** แอปอัดเสียงเป็น WAV 16 kHz เองในเบราว์เซอร์ เพราะ Typhoon รับไฟล์ webm/mp4 ที่เบราว์เซอร์อัดตามปกติไม่ได้
- **ความปลอดภัยมาก่อน:** ถ้าพูดถึงอาการฉุกเฉิน (เจ็บแน่นหน้าอก หายใจลำบาก หน้าเบี้ยว ฯลฯ) หรืออยากทำร้ายตัวเอง แอปตอบเองทันทีด้วยกฎในเครื่อง พร้อมปุ่มโทร 1669 / 1323 โดย**ไม่ส่งให้ AI**
- **Worker ล็อกคำสั่งระบบ (system prompt) เอง:** เว็บแก้ไม่ได้ สั่งให้ AI ตอบสั้น ไม่วินิจฉัย ไม่แนะนำยา และแนะนำ 1669 เมื่อฉุกเฉิน
- **ต้องยินยอมก่อน:** ครั้งแรกจะแสดงหน้าอธิบายว่าเสียงและข้อความถูกส่งไปที่ไหน ถอนความยินยอมได้ในหน้าคุย ถ้าไม่ยินยอมหรือเซิร์ฟเวอร์ล่ม จะตอบแบบออฟไลน์แทน

**สังเกตน้ำเสียงและอารมณ์ (ทดลอง ต้องเปิดเอง)**

```
เสียง → [ในเครื่อง] วัดระดับเสียง (pitch) การขึ้นลงของเสียง ความดัง ความเร็วพูด ช่วงหยุด
      → เทียบกับ "เสียงปกติของคุณ" (ค่ามัธยฐานของ 15 ครั้งล่าสุด เก็บในเครื่องนี้เท่านั้น)
      → ได้รหัสสัญญาณ เช่น fast, pitch_up → Worker แปลงเป็นคำ ใส่ใน prompt
      → Typhoon ประเมินจากคำพูด + น้ำเสียง → calm / stressed / anxious / sad / tired / unclear + ความมั่นใจ
```
- เปิดได้ตอนกดยินยอม (ช่องติ๊ก ค่าเริ่มต้นปิด) หรือปุ่ม "สังเกตน้ำเสียง" ใต้ไมค์ ปิดแล้วลบค่าเสียงปกติทิ้งทันที
- 3 ครั้งแรกเป็นช่วงเรียนรู้เสียงปกติ ระหว่างนี้ AI ดูจากคำพูดอย่างเดียว
- ส่งให้ AI เฉพาะรหัสสัญญาณที่ Worker รู้จัก ไม่ส่งตัวเลขเสียง และ Worker ทิ้งรหัสอื่นทั้งหมด
- AI ถูกสั่งให้ถือคำพูดเป็นหลัก ถ้ามีแค่น้ำเสียงให้ความมั่นใจต่ำ และห้ามฟันธง
- ผลแสดงเป็นคำถาม "คุณอาจกำลังเครียด ใช่ไหมคะ" หลังน้องสุขใจพูดจบ ตอบ ใช่/ไม่ใช่ ได้ ถ้าใช่ จะแนะนำการหายใจ และชวนทำแบบประเมิน
- ถ้ามั่นใจระดับกลางขึ้นไป น้องสุขใจทำหน้ากังวลและพูดช้าลง
- **แบบประเมินของกรมสุขภาพจิต** ในหน้าคุย: ความเครียด ST-5 (5 ข้อ คะแนน 0–4 / 5–7 / 8–9 / 10–15) และคัดกรองซึมเศร้า 2Q คำตอบอยู่ในเครื่อง ไม่ส่งให้ AI ไม่บันทึก

**ท่าทางตัวละคร (จากแผ่นออกแบบ)**

| สถานะ | ท่าทาง |
|---|---|
| เปิดหน้าคุย | ท่า Side/Walk เดินเข้ามา แล้วหันหน้า |
| พร้อม/ฟัง | ท่า Front/Wave หายใจ โยกตัว |
| คิด | โยกซ้ายขวา + ฟองความคิด "…" |
| พูด | ปากขยับ |
| ฉุกเฉิน | หน้า Surprised + สะดุ้ง |
| ดีใจ | ท่า Excited กระโดดถือลูกโอ๊ก |

## วิธีติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### 1. ขอ API key ของ Typhoon (ฟรี)
1. เข้า **playground.opentyphoon.ai** แล้วสมัคร/ล็อกอิน
2. ไปที่หน้า API Key แล้วสร้าง key ใหม่
3. เก็บ key ไว้ **ห้ามใส่ใน `index.html` หรือ push ขึ้น GitHub**

### 2. สร้าง Cloudflare Worker (ฟรี)
**วิธีง่าย ผ่านหน้าเว็บ:**
1. สมัคร/ล็อกอิน **dash.cloudflare.com** → เมนู **Workers & Pages** → **Create** → **Create Worker** → ตั้งชื่อ `sookjai-ai` → **Deploy**
2. กด **Edit code** → ลบโค้ดเดิม → วางเนื้อหาทั้งหมดของ `worker/worker.js` → **Deploy**
3. ไปที่ **Settings → Variables and Secrets** แล้วเพิ่ม 2 ค่า:
   - `TYPHOON_API_KEY`: เลือกชนิด **Secret** ใส่ key จากข้อ 1
   - `BOTNOI_TOKEN`: ชนิด **Secret** ใส่ API key จาก voice.botnoi.ai/developer/api (ไม่ใส่ก็ได้ จะใช้เสียงในเครื่องแทน)
   - (ไม่บังคับ) `BOTNOI_SPEAKER`: รหัสเสียง ค่าเริ่มต้น 23 = โบ (Bow V2), 65 = คุณงาม (Ngam), 328 = น้องแอปเปิ้ลพาย (ถ้าใช้ v1 โบคือรหัส 2) · `BOTNOI_VERSION`: v2 (ค่าเริ่มต้น) หรือ v1 (ถูกกว่าครึ่ง รหัสเสียงคนละชุด)
   - `ALLOWED_ORIGINS`: ชนิด Text ใส่ `https://chaiporn2005.github.io,http://localhost`
4. คัดลอก URL ของ Worker เช่น `https://sookjai-ai.xxxx.workers.dev`

**หรือใช้คำสั่ง (ถ้าถนัด):**
```
cd worker
npx wrangler login
npx wrangler secret put TYPHOON_API_KEY
npx wrangler deploy
```

### 3. เชื่อมแอปกับ Worker
เปิด `index.html` ค้นหา `const AI_ENDPOINT = '';` แล้วใส่ URL จากข้อ 2 (ไม่มี `/` ปิดท้าย):
```js
const AI_ENDPOINT = 'https://sookjai-ai.xxxx.workers.dev';
```
URL นี้ใส่ในโค้ดได้ปลอดภัย เพราะ key อยู่ใน Worker และ Worker รับเฉพาะคำขอจากเว็บที่ระบุใน `ALLOWED_ORIGINS`

### 4. (แนะนำ) สร้างเสียงอัดของประโยคตายตัว
หลังมีแต้ม Botnoi พอ (ทั้งชุดประมาณ 1,460 แต้ม) รันในโฟลเดอร์นี้:
```
node tools/make-voice.mjs --dry   # ดูว่าขาดไฟล์ไหน ใช้กี่แต้ม
node tools/make-voice.mjs         # สร้างทุกไฟล์ที่ยังไม่มี (หรือใส่ชื่อ เช่น hero-poke-1 hero-poke-2)
```
แล้ว commit โฟลเดอร์ `voice/` ขึ้น GitHub จะอัดเสียงคนจริงแทนก็ได้ แค่ตั้งชื่อไฟล์ให้ตรง

### 5. เปิดบนมือถือ
ไมโครโฟนใช้ได้เฉพาะเว็บ **HTTPS** ให้ push ขึ้น GitHub Pages (เหมือนโปรเจกต์เดิม) แล้วเปิดลิงก์บนมือถือ → กด "คุยด้วยเสียงกับน้องสุขใจ" → ยินยอม → อนุญาตไมโครโฟน → แตะไมค์แล้วพูด

## ข้อจำกัด

- ภาพตัวละครมาจากแผ่นออกแบบความละเอียด 1376×768 ตัวละครแต่ละท่าจึงกว้างแค่ประมาณ 314 px บนจอมือถือความละเอียดสูงจะดูนุ่มเล็กน้อย ถ้ามีไฟล์ตัวละครแยกท่าความละเอียดสูง (เช่น PNG 1000 px+) จะคมขึ้นมาก
- ปากขยับเป็นพยางค์หลายระดับ (ช่องแคบ ครึ่ง กว้าง) และหุบเว้นจังหวะคำ ถ้าเบราว์เซอร์แจ้งตำแหน่งคำขณะอ่านออกเสียง (`onboundary`) จะขยับตรงจังหวะนั้น ถ้าไม่แจ้งจะใช้จังหวะสุ่มที่ใกล้เคียงการพูด จึงยังไม่ตรงกับพยางค์จริงทุกพยางค์
